# 合规表达说明

## 为什么要使用中性表达

举报、情况反映、申诉和信息公开申请应尽量围绕事实、证据、影响和请求事项展开。中性表达可以降低误解和法律风险，也更便于接收部门核查和回复。

建议使用：

- “相关安排的依据有待进一步说明”
- “部分学生反映受到影响”
- “希望明确复核渠道”
- “请依法依规核查处理”

避免使用：

- 侮辱性称呼
- 动机推断
- 未经证实的严重定性
- 鼓励刷屏或骚扰的表达

## 哪些词属于高风险词

仓库中的 `data/risk-terms.json` 默认列出以下高风险词：

- 腐败
- 贪污
- 黑幕
- 迫害
- 恶意打压
- 欺骗学生
- 违法犯罪
- 利益输送
- 官僚主义

这些词并非绝对不能出现，但通常需要明确事实、证据和依据。没有充分证据时，应改为更具体、更克制的事实描述或程序性请求。

## 哪些事实需要证据

以下表达通常需要证据支撑：

- 涉及数据变化，如排名下降、经费下降。
- 涉及范围绝对化，如所有学生、完全没有依据。
- 涉及程序性判断，如从未征求意见、反馈无门。
- 涉及法律结论，如严重违法。

如果没有证据，建议改成“部分学生反映”“尚未充分说明”“反馈渠道不够明确”等谨慎表述。

## 为什么不能公开个人隐私

公开他人姓名、联系方式、证件号、宿舍号、人脸、车牌、聊天头像、聊天昵称等信息，可能造成隐私侵害和二次伤害，也会削弱材料的正当性。提交截图、照片、聊天记录和文档前，应先完成脱敏。

## 为什么不能冒名或代表未经授权的人

反映材料应由本人或获得授权的人提交。冒名署名、代替未经授权的人表达意见，可能引发身份、授权和真实性风险。材料中如使用“我们”，应确认是否确有共同授权；不确定时使用“本人”或“部分学生反映”。

## 为什么不做自动群发

自动群发容易造成骚扰、刷屏和渠道滥用，也可能让用户在未审阅内容的情况下提交不准确材料。本项目只提供邮件草稿打开功能，用户必须自行核对事实、证据、措辞、个人信息和附件脱敏情况后，再决定是否发送。

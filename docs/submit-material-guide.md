# 材料提交指南

## 欢迎提交

- 官方通知截图。
- 公开网页链接。
- 已脱敏聊天记录。
- 公共区域照片。
- 个人经历描述。
- 渠道补充。
- 模板建议。
- 事实纠错。
- 合规风险提醒。

## 不接受

- 未脱敏材料。
- 侮辱性内容。
- 无证据严重指控。
- 私人联系方式。
- 人肉信息。
- 鼓励骚扰或刷屏的内容。

## 提交事实材料

事实材料应尽量包含时间、来源、发生范围、已知影响和证据编号。不要加入无法核实的动机推断，不要扩大为“所有人”“完全没有”等绝对化表述。

## 提交证据材料

证据材料应优先使用公开通知、公开网页、已脱敏截图、公共区域照片和可核验文档。所有材料提交前必须脱敏，并说明来源和时间。

## 提交渠道信息

渠道信息应来自公开、正式、可核验来源。请不要提交私人手机号、私人邮箱、个人社交账号或未经公开授权的联系方式。

## 提交合规风险提醒

如果发现模板、事实、证据或 UI 文案中存在高风险措辞、隐私泄露风险、误导性表达或可能引发骚扰的设计，请优先提交修正建议。

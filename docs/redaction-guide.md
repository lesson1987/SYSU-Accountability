# 材料脱敏指南

提交或引用截图、照片、聊天记录、文档前，应先遮盖或删除可识别个人身份的信息。

## 必须脱敏的信息

- 姓名
- 学号
- 手机号
- 身份证号
- 宿舍号
- 门牌号
- 微信号
- QQ号
- 邮箱
- 人脸
- 车牌
- 聊天头像
- 聊天昵称
- 私人联系方式

## 截图脱敏

1. 遮盖聊天头像、昵称、备注名和联系方式。
2. 遮盖学号、手机号、邮箱、宿舍号、门牌号等字段。
3. 遮盖图片中的人脸、车牌和可定位到个人住处的信息。
4. 保留与事实相关的时间、通知内容、公开标题和必要上下文。

## 文档脱敏

1. 删除文档属性中的作者、公司、修订记录等元数据。
2. 遮盖正文、页眉、页脚和附件中的个人信息。
3. 如有签名、证件号、联系方式，应替换为“已脱敏”。
4. 提交前重新导出一份脱敏版本。

## 照片脱敏

1. 模糊或裁掉人脸。
2. 模糊车牌、门牌和宿舍门号。
3. 避免上传能定位私人住处或个人行动轨迹的照片。
4. 公共区域照片应只用于说明客观情况。

## 表述脱敏

文字描述中也应避免写入他人的姓名、宿舍号、联系方式、账号、班级小范围身份等信息。确需说明时，可使用“某同学”“部分学生”“相关人员”等概括表述。
